System Overview Platform Architecture

MySilah CRM is a B2B2C lead management platform connecting Customers → Agents → Agencies → Banks. Agents capture customer leads for credit cards and personal loans. Agencies review and process them. Commissions flow back through the chain once a lead is approved and disbursed.

Role Summary

🛡 Admin

Full system access. Manages all users, products, leads, commissions, and platform content.

  • Created internally — no registration
  • 20+ management screens
  • Can override any lead state
  • Manages commission payouts

🏢 Agency

Company entity managing a team of agents and employees. Reviews, assigns, and processes leads.

  • Self-register (admin approval) or admin-invite
  • Manages internal employees
  • Controls lead pipeline for their agents

👤 Agent

Field-level user who captures customer leads and tracks commissions. Earns per approved disbursed lead.

  • Self-registers with email verification
  • Also supports UAE PASS
  • Earns commissions per product brackets

🔧 Employee

Agency's internal staff (CPV verifier or Sales). Assigned to leads for on-ground processing.

  • Created by agency — never self-registers
  • Types: cpv or sales
  • Marks CPV / activation / spend tasks

✍️ Blog Editor

Content-only role for managing the MySilah blog. No access to leads or financial data.

  • Created directly by admin
  • Access: blog posts only
  • No approval flow needed

Registration & Onboarding

  • 1
    Visit /register

    Fill: Full Name, Email, Password, Phone (UAE), Emirates ID (optional). Accept Terms.

  • 2
    Or — UAE PASS

    Sign in with UAE PASS for instant Emirates ID verification. Prefills name, phone, Emirates ID.

  • 3
    Email Verification

    Verification link sent. Agent must click to activate before login.

  • 4
    Login → /agent Dashboard

    Monthly stats: total leads, approved count, commissions earned.

Lead Submission Flow

  • 1
    New Lead → /agent/leads/new

    Select product type (Credit Card or Personal Loan). Pick bank product from dropdown.

  • 2
    Fill Customer Details

    Name, Phone, Email, Nationality, Visa Type, Salary, Company, Job Title, Loan Amount (if loan). Lead auto-numbered: LD-ABCDEF-0001

  • 3
    Save as Draft

    Status: DRAFT WhatsApp consent auto-sent to customer.

  • 4
    Send to Agency

    Status: SUBMITTED Agency notified. Lead locked from edit.

  • 5
    Track Progress

    Monitor status at /agent/leads. Track commissions at /agent/commissions.

Employee Journey Created by Agency · CPV or Sales type

Employees are internal agency staff — they never register themselves. The agency creates their account and sets credentials. Two types: CPV (Customer Presence Verification) and Sales (activation & spend tracking).

Account Creation (by Agency)

  • 1
    Agency → /agency/employees

    Clicks "Add Employee". Enters name, email, phone, type (cpv or sales).

  • 2
    Agency Sets Password

    Via "Change Password" action. Shares credentials with employee offline.

  • 3
    Employee Logs In → /employee

    Sees only leads assigned to them.

Lead Processing Tasks

  • 1
    View Assigned Leads → /employee/leads

    Agency has assigned them. Employee sees customer info and current status.

  • 2
    Mark CPV Done

    (CPV type) Verify customer physical presence / ID. Mark cpvDone ✓

  • 3
    Mark Activation Done

    (Sales type) Card/loan activated with bank. Mark activateDone ✓

  • 4
    Mark Spend Done

    (Credit card) Customer meets minimum spend. Mark spendDone ✓ — triggers hold release eligibility.

  • 5
    Update Consent & Loan Status

    Track WhatsApp consent and loan processing stage via custom labels.

Admin Journey Full system access · Internally created

Admin accounts are created internally — no public registration. Admin has full read/write access to every entity. Key responsibilities: approve agencies, manage products, oversee lead pipeline, process commission payouts.

Admin Capabilities Overview

User Management
  • Approve / reject self-registered agencies
  • Create agents & agencies directly
  • Toggle any user active/inactive
  • View per-agent lead stats & earnings
  • Create blog editors
Lead Management
  • View ALL leads across all agents/agencies
  • Override any lead status transition
  • Set / override agent commission (% or fixed)
  • Delete leads entirely
  • Bulk: mark paid, mark received, release holds
Product Management
  • Create / edit banks
  • Create / edit credit card products
  • Create / edit loan products
  • Set commission brackets per product
  • Restrict products to specific agencies
System & Content
  • Manage custom employee statuses
  • Post notices to users
  • Upload / manage legal pages
  • View reports & consent logs
  • Manage blog category images

Lead Lifecycle Full Status Flow

Status Pipeline

DRAFT→ SUBMITTED→ UNDER REVIEW→ ASSIGNED→ APPROVED→ DISBURSED
Any active status → REJECTED (terminal · commission voided)

Detailed Status Transitions

FromToWhoWhat happens
DRAFT SUBMITTED Agent Agent clicks "Send to Agency". WhatsApp consent auto-sent. Lead locked from agent edits.
SUBMITTED UNDER REVIEW Agency Admin Agency reviews customer details, may update loan amount. Employee label set to "New Lead".
UNDER REVIEW ASSIGNED Agency Admin CPV/Sales employee assigned. Employee notified. Tasks queued.
ASSIGNED APPROVED Agency Admin Bank confirms approval. Commission bracket calculated. Commission status → pending.
APPROVED DISBURSED Agency Admin Agency uploads disbursement receipt. Commission → payable.
Any active REJECTED Agency Admin Employee Bank declined or customer dropped out. Terminal. Commission voided.

Agent updates engagement status independently from main lead status to track customer interaction.

Loan Commission

  • Calculated from product's commission brackets
  • Typically % of approved loan amount
  • Moves to payable after disbursement
  • No hold mechanism for loans
  • Admin marks paid + records payment date

Credit Card Commission

  • Fixed amount per approved card
  • Hold amount withheld until minimum spend confirmed
  • Employee marks spendDone ✓
  • Admin releases hold → full commission becomes payable
  • Bulk hold-release available for admin

Lead Number Format

Every lead auto-assigned unique number on creation: LD-ABCDEF-0001
Format: LD prefix — 6-char agent code — 4-digit sequence per agent.
Reference number is separate and manually set (e.g. bank application ID).
